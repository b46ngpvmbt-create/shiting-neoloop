# 石听 NeoLoop｜4 分 30 秒 Demo 视频脚本

## 统一口径

全片左上角固定显示“合成演示”。公开事实、待企业验证、方案设计、合成实验分开标注。只有已经取得运行记录的步骤才使用“验证结果”；其余步骤统一写“设计路径”或“预期行为”。

视频不出现真实客户、车辆、任务、赛事凭证、飞书资源 ID、OAuth 信息或企业内部资料。所有演示对象保持 `SYN` 前缀，主故事固定为：

`SYN-CASE-017 → SYN-CLUSTER-001 → SYN-IMPROVEMENT-001`

## 录制与验收

1. 成片时长控制在 4:25–4:35，输出 1920×1080、H.264、AAC，字幕不低于 36 px。
2. Web 录屏只使用只读公开快照；渠道按钮不触发真实接口，不保存数据，不写飞书。
3. 取得运行证据前，不把合成故障规格说成“已经通过”，不把 owner 可见成品说成权限验收完成。
4. 所有版本号、对象 ID、步骤名称和状态必须与视觉附录、Web 和体验包一致。
5. 上传后以未登录环境从头播放一次，检查权限、声音、字幕、清晰度、敏感信息与链接。

## 全片禁说项

- 已接入新石器真实数据、生产接口或真实业务全渠道。
- AI 自动判责、定赔、承诺恢复时间、确认最终根因或控制车辆。
- 合成案件是真实客户投诉，合成时钟是真实连续运行时间。
- 本地测试、离线包、Web 原型或 owner run 等同于企业生产能力。
- 没有原始记录和企业金标准支持的效率、成本、收入、复发率或 ROI。
