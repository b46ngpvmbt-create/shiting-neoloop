# 石听 NeoLoop｜工作台使用说明录屏 V5 设计

日期：2026-08-13  
状态：本人已确认，待实施  
范围：仅制作独立工作台录屏，不覆盖 V1—V4，不合成最终五分钟成片

## 1. 目标

把原先由截图和缓慢推拉构成的 Web 段落改为真实连续操作录屏，使评委能理解工作台如何使用，而不只看到界面结果。

本段只演示公开合成快照和浏览器内存沙盘，不保存数据、不请求飞书、不触发外部工作流。

## 2. 输出

- 原始连续录屏：保留真实鼠标移动、滚动、输入和点击。
- 剪辑候选：约 75—95 秒，1920×1080、30 fps、H.264。
- 不添加旁白和字幕；为后续与飞书及其他视频合成预留音画同步空间。
- 文件使用 V5 独立命名，V1—V4 原文件与校验值保持不变。

## 3. 操作顺序

1. 工作台概览：显示合成只读、未连接企业系统和统一操作指引。
2. 反馈收件箱：展示来源、来源类型、授权范围和案件关联。
3. 固定证据链：打开 `SYN-CASE-017` 证据检查器，展示对象关系、人工关口和安全边界。
4. 本地沙盘：执行反馈接入、分诊候选和实体候选。
5. 人工治理：打开退回补证，输入明确原因，提交退回。
6. 补证重提：展示返回节点与下一责任角色，模拟补证并重新提交，再确认通过。
7. 双循环推进：分别通过责任关口，建立本地工单，关闭个案，生成问题簇候选并人工立项。
8. 完成页：停留在 `10 / 10`，展示个案闭环、改进闭环和本地退回次数。

## 4. 录制与剪辑规则

- 采用真实浏览器操作，不以截图序列伪装录屏。
- 鼠标每次移动都服务于下一个操作；重要结果停留 1.0—2.0 秒。
- 删除加载、找按钮、误点、重复动作和超过 2 秒的无信息停顿。
- 允许在剪辑中使用 1.1—1.35 倍速度压缩普通导航，不加速人工退回输入与关键结果。
- 页面保持原始亮度，不加全屏暗层、大标题或底部遮罩。
- 最终五分钟合成时再加无底字幕；字幕不得遮挡当前按钮和状态。

## 5. 证据边界

- 全部对象使用 `SYN` 前缀和合成数据。
- 不展示账号、令牌、OAuth、飞书资源 ID 或内部数据。
- 不表述为真实企业数据接入、生产上线、AI 自动判责、企业效率提升或最终根因确认。
- Web、飞书与离线包继续作为三层独立证据，不能互相替代。

## 6. 验收

- 录屏中能看到连续鼠标操作、按钮反馈、表单输入和状态推进。
- 退回补证、补证重提和再次确认链路完整。
- 关键页面文字在 1080p 下可读，无横向裁切、黑帧或系统通知遮挡。
- 视频可独立播放，时长 75—95 秒，音轨为空或静音，不覆盖任何旧文件。
- 生成关键时间点联系表，至少覆盖收件箱、案件抽屉、退回表单、已退回、已重提和 10/10 完成页。

## 7. 后续合成

本段验收后再替换 V4 中的 Web 截图段，并与飞书落地、证据边界和片尾合成新版本。新总片必须少于 5 分钟，且继续保留 V1—V4。
