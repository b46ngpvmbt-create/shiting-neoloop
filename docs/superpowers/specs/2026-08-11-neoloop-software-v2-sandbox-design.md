# 石听 NeoLoop｜运营工作台 V2 与本地沙盘设计

日期：2026-08-11  
状态：用户确认“改”，按已给出的优化清单实施  
入口：`/software`

## 1. 变更契约

- 受众：赛事评委和教练。
- 主要结果：评委能从一条带来源的合成反馈出发，在 60–90 秒内理解个案闭环和改进闭环。
- 核心行动：浏览冻结快照；切换到本地沙盘；逐步执行预定候选、人工确认和观察步骤；一键重置。
- 受影响页面：仅 `/software`，首页只保留现有入口。
- 数据来源：继续使用 `app/public-snapshot.ts` 中的公开合成快照；渠道来源详情由前端确定性适配器派生，并标记为“合成显示字段”。
- 外部集成：无。不读写飞书，不发送请求，不保存浏览器沙盘状态。
- 回滚目标：保留 V1 规范和 Git 历史，V2 失败时可回退到现有只读五模块页。

## 2. 方案选择

### A. 只扩充右侧字段

开发量小，但仍是“可点击的数据展板”，无法表现硬规则、AI 候选和人工关口如何协作。

### B. 企业工作台 + 本地沙盘（采用）

冻结快照和沙盘共用同一条合成故事，但用明确模式开关隔离。快照回答“现在有什么证据”，沙盘回答“系统如何工作”。交互更完整，同时不会把本地状态写成生产运行。

### C. 构建可写后端原型

可增加“真软件”感，但会引入数据库、身份和接口边界，与赛事当前的合成证据层不匹配，本轮不做。

## 3. 信息架构

- 顶栏：产品名、“合成快照 / 本地沙盘”切换、边界状态、返回展示页。
- 左侧导航：五个业务模块，导航文案优先中文任务，去掉装饰性编号。
- 主区：标题、简要说明、故事链或沙盘进度、搜索筛选、模块专属内容。
- 证据抽屉：选中记录时从右侧打开，展示字段、关系、人工关口和安全边界；支持关闭和 Escape。
- 手机端：顶栏精简，模块导航横向滚动，证据抽屉占满屏幕宽度。

## 4. 反馈来源

收件箱列表直接显示：

- 渠道类型；
- 来源系统；
- 合成来源记录 ID；
- 接收时间；
- 授权状态；
- 幂等键；
- 原始内容摘要；
- 关联案件。

公开快照尚未提供全部来源合同字段，因此不修改 canonical 业务合同，不伪造企业资源 ID。页面根据现有渠道和合成 ID 生成稳定、可复现的展示值，并在字段组中明示“合成显示字段”。

## 5. 本地沙盘

沙盘固定使用 `SYN-CASE-017 → SYN-CLUSTER-001 → SYN-IMPROVEMENT-001`，不接收任意文本。

顺序为：

1. 合成反馈接入和幂等校验；
2. 硬规则检查与 AI 分诊候选；
3. 车辆、任务和站点候选；
4. 人工确认正式实体；
5. 人工确认责任路由；
6. 工单与原 SLA 时钟；
7. 处置证据、回访和人工关闭；
8. 跨事件问题簇候选；
9. 人工立项与 7/30 天观察；
10. 归档或复发重开的预期路径。

每步仅修改 React 内存状态，显示预定输入、执行层、证据和下一步。AI 步骤只返回预置合成候选；人工关口必须通过独立按钮确认。顶部始终显示“本地沙盘 · 刷新即重置 · 不触发外部系统”。

## 6. 模块专属表达

- 案件驾驶舱：增加从接入、分诊、关联、路由到回访的时间线。
- SLA 协同板：按“需要关注 / 进行中 / 已完成”分组，保留原始时钟和重置次数。
- 问题地图：用成员案件、站点和车型节点表示问题簇关系，不把视觉连线当成已确认根因。
- 改进追踪：使用立项、7 天、30 天、结论四节点时间线，未运行项统一显示为空状态。

## 7. 视觉方向

- 背景使用浅灰绿，主表面使用白色，主文字使用深灰，品牌绿仅用于选中、确认和路径。
- 主信息统一使用无衬线字体；衬线字只保留在品牌小标识。
- 去掉方格纸背景、过密的细分割线、大量全大写英文和装饰性数字。
- 不使用玻璃浮层、强发光、浓重渐变或过量阴影。
- 列表默认优先固定故事，减少首屏记录数；更多快照通过筛选和搜索查看。

## 8. 错误与恢复

- 搜索无结果时提供“重置视图”。
- 沙盘步骤不允许跳过；当前步骤按钮明确说明会发生的本地变化。
- “重置沙盘”需二次确认，确认后恢复初始状态。
- 关闭证据抽屉后焦点返回原记录。
- 刷新页面自动丢弃沙盘进度，不使用 localStorage。

## 9. 验收

- 收件箱首屏可看到渠道、来源系统、来源记录 ID、授权状态和关联案件。
- 快照和沙盘模式有明确视觉和文案边界，沙盘不调用 `fetch`、不使用写方法、不保存状态。
- 固定故事的 10 步可依次演示，人工关口与 AI 候选步骤在文案和视觉上可区分。
- 五模块具有不同的高价值表达，不再只是同一列表换数据。
- 桌面端 1440×900、手机端 390×844 无横向溢出；键盘操作、焦点、抽屉和 Escape 通过。
- Node 22.13.0 下 lint、渲染测试、公开快照测试、生产构建与 Netlify 静态导出通过。
- 禁止出现“真实数据已接入”“AI 自动判责”“最终根因已确认”等无证据表述。
- 本轮不部署、不推送、不建 Release、不提交赛事材料。
