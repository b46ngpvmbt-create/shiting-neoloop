# 石听 NeoLoop 工作台按钮操作契约设计

日期：2026-08-12  
状态：待实施  
范围：`/software` 本地工作台

## 1. 目标

消除只有外观、没有完整操作结果的控件。每个按钮必须具备明确的操作前说明、状态变化、结果反馈和下一步；无法安全执行的动作必须显示为说明性状态，不伪装成已运行按钮。

工作台继续只读取公开合成快照。沙盘操作只修改当前浏览器内存，不写真实数据，不触发飞书、车辆控制、通知或外部接口。

## 2. 统一按钮契约

每个按钮至少对应以下四项：

1. `actionId`：稳定动作标识。
2. `intent`：点击前说明将要执行的本地操作。
3. `result`：点击后可见的完成状态、目标对象和结果。
4. `nextStep`：明确建议的下一步。

按钮点击后写入当前页面内存中的操作记录。记录不进入本地存储，刷新即清空。

## 3. 两个统一反馈区域

### 当前操作指引

- 位于主要工作区上方。
- 初始状态根据当前模式给出第一项建议操作。
- 切换模块、打开对象或进入沙盘步骤后同步更新。
- 文案使用“可以查看”“将在本地模拟”等边界明确的表达。

### 最近操作结果

- 展示最近一次动作的名称、对象、结果和下一步。
- 使用 `aria-live="polite"`，供键盘和辅助技术读取。
- 状态分为 `ready`、`success`、`warning`；不得使用真实生产成功语义。

## 4. 快照模式按钮

| 按钮类别 | 动作 | 结果 | 下一步 |
| --- | --- | --- | --- |
| 合成快照 | 进入只读快照 | 定位反馈收件箱固定故事 | 选择模块或记录 |
| 五个模块 | 切换当前业务视图 | 重置搜索，选中固定故事 | 查看高亮区或记录 |
| 固定证据链 | 切换模块并打开对象 | 展示对应证据抽屉 | 查看关系、人工关口和边界 |
| 高亮区按钮 | 打开当前故事证据 | 展示证据字段 | 关闭抽屉或切换记录 |
| 记录行 | 选中记录并打开抽屉 | 展示该记录解释层 | 核对证据分类与关系 |
| 关闭抽屉/遮罩 | 关闭解释层 | 焦点返回原触发按钮 | 继续浏览 |
| 搜索 | 实时过滤当前模块 | 展示条件与结果计数 | 打开结果或清除条件 |
| 筛选 | 切换固定故事/关注/全部 | 展示筛选结果 | 打开结果或清除条件 |
| 重置视图 | 清除搜索并恢复固定故事 | 列表恢复 | 选择记录 |

搜索和筛选属于输入操作，但必须进入相同的结果反馈体系。

## 5. 沙盘模式按钮

### 普通步骤

点击前右侧标题为“本步预期输出”。点击后：

1. 写入本地操作记录。
2. 显示本步“已完成本地演示”。
3. 展示对象 ID、结果和边界。
4. 进入下一步骤并更新指引。

### 四个人工关口

- `确认通过`：写入本地批准记录，再进入下一步。
- `退回补证`：打开原因表单；至少四字；提交后显示返回节点、下一责任角色和批次。
- `驳回候选`：打开原因表单；提交后保留原状态并显示驳回目标。
- `模拟补证并重新提交`：产生重提记录和批次，再次显示确认、退回、驳回三项决策。

人工关口不显示真实审核人、企业账号或外部通知结果。

### 重置

- 第一次点击仅进入待确认状态。
- `确认重置` 清空步骤、审查支线、操作记录和反馈状态。
- `取消` 返回原状态，不清除进度。

## 6. 导航链接

- 品牌链接和“返回展示页”均导航到 `/`。
- 链接具有明确的可访问名称。
- 本轮不改变首页内部交互；只验证工作台返回链路。

## 7. 实现结构

- 在 `app/software/page.tsx` 内新增轻量 `ActionFeedback` 类型和统一反馈组件。
- 快照按钮通过一个动作报告函数写入结果，避免各按钮自行拼接不一致文案。
- 沙盘步骤在推进前写入完成事件；现有 `reviewEvents` 继续保存审查支线，通用操作使用独立日志。
- `workbench-data.ts` 为十个沙盘步骤补充稳定 `actionId`、操作意图和成功文案。
- 不引入后端、数据库、网络请求或浏览器持久化。

## 8. 异常与边界

- 搜索无结果时显示空状态及“重置视图”。
- 人工原因不足四字时保留表单并显示错误，不写入成功记录。
- 重复点击当前模式或当前模块仍返回明确“当前已在此模式/模块”的反馈，不伪造新动作。
- 当前对象不存在时不打开空抽屉，显示 warning 反馈。
- 所有操作记录明确标记“本地演示”。

## 9. 验收

- 建立按钮契约测试：所有工作台按钮或链接必须拥有动作处理、导航目标或明确关闭语义。
- 自动验证十个沙盘步骤、四个人工关口、退回/驳回/重提、重置确认和取消。
- 浏览器逐项验证五个模块、四个故事对象、记录抽屉、搜索、三类筛选和空状态恢复。
- 验证桌面、手机、键盘焦点、Escape、`aria-live` 与控制台错误。
- `npm run check:release` 通过。
- 用户本人验收前不部署；用户明确验收通过后，才进入 Netlify Preview 阶段门。

## 10. 非目标

- 不把快照视图改成真实数据编辑器。
- 不连接飞书或企业系统。
- 不新增车辆控制、责任判定、赔偿、最终根因确认或真实通知。
- 不在本轮修改首页自由展示区按钮。
