# 石听 NeoLoop｜自由展示区交互式证据展区设计

日期：2026-08-11  
状态：用户已批准，进入实施  
范围：公开 Web Demo、40 强作品自由展示区、视觉附录、Demo 视频、离线评委体验包

## 1. 目标与受众

面向 40 强赛评委，用一条可点击、可复现、可审计的合成故事说明石听 NeoLoop 的原创设计：全渠道反馈不是停在人工录入，而是经过统一接入、个案处置、跨事件改进与复发观察形成双循环。

固定故事链为：

`SYN-CASE-017 → SYN-CLUSTER-001 → SYN-IMPROVEMENT-001`

90 秒体验必须让评委理解：

1. 反馈可从 App、客服、热线转写、邮件、飞书和经授权公开平台自动进入原始反馈池。
2. 个案闭环解决一次反馈，改进闭环处理不同事件中的同类问题。
3. AI 只产生候选、证据和草稿；硬规则、权限与人工关口先于模型建议。
4. Web 体验、真实飞书落地、离线工程验证属于不同证据层，不能互相冒充。

## 2. 交互设计

公开站首页新增两个只读区域。

### 2.1 `#dual-loop` 双循环交互舞台

- 顶部以六个渠道卡汇入不可覆盖的“原始反馈池”；渠道只选择冻结合成事件，不接收任意文本。
- 左侧个案闭环固定六步：接入幂等、AI 分诊、实体关联、人工确认、工单与 SLA、回访关闭。
- 右侧改进闭环固定五步：跨事件聚类、根因假设、人工立项、7/30 天观察、归档或复发重开。
- 关闭后的案件进入问题簇候选；复发箭头返回处置与改进，不把不同事件合并成一个案件。
- 点击步骤后显示：当前输入、AI 作用、证据/缺失项、人工关口、预期输出、证据类别与执行状态。
- 页面全程显示“合成设计回放 · 不写数据 · 不触发外部工作流”。

### 2.2 `#value-lab` 企业参数测算器

- 输入：月反馈量、当前人工分诊分钟/条、辅助后分钟/条。
- 输出公式：`月度理论释放小时 = 月反馈量 × max(当前耗时 - 辅助后耗时, 0) ÷ 60`。
- 默认合成假设：1000 条/月、8 分钟/条、3 分钟/条，输出 83.3 小时/月。
- 输入设置上下界并支持键盘；辅助后耗时大于当前耗时时输出 0，不显示负收益。
- 结果固定写“参数化测算，不是新石器真实业务成效”。

## 3. 统一视觉与证据语言

- 确定性工作流：蓝色。
- AI 候选：紫色。
- 硬规则/安全停点：红色。
- 人工关口：琥珀色。
- 证据状态：青色；未运行继续使用灰色。
- 动效只用于指示数据流和当前步骤；`prefers-reduced-motion` 下取消循环和位移动画。

证据标签继续使用四类：公开事实、待企业验证、方案设计、合成实验。没有现场证据时不得显示“已上线”“已接入真实数据”“验证通过”“企业效率提升”。

## 4. 多载体一致性

同一双循环顺序同时进入：

1. Web 交互；
2. 视觉附录第 3 页与静态兼容图；
3. 4 分 30 秒 Demo 视频；
4. 飞书作品文档自由展示区；
5. 离线评委体验包的打开说明。

Web 从现有公开快照只读派生，不修改 canonical 业务合同。`POST /v1/feedback` 只作为未部署的接入协议展示，公开 Demo 不导入服务、不读取凭证。

## 5. 交付与边界

离线包固定命名为 `石听NeoLoop_评委体验包_v1.zip`，包含打开说明、10 页视觉附录 PDF、三份 Excel、10 表 240 字段合成导入样例、体验链接/二维码与 SHA-256 清单。

不包含：`node_modules`、本机绝对路径、私有配置、OAuth 信息、真实飞书资源 ID、内部证据、失败暂存目录或未经授权个人信息。源码只提供公开 GitHub 链接。

总控继续独占飞书 Base、AI 节点、工作流、权限和现场证据。本实施只消费经过验证的冻结状态，不操作飞书。

## 6. 验收

- Web：桌面、移动、键盘、焦点、减少动态效果、控制台、正式 Node 22.13 构建通过。
- 内容：四种载体步骤与名称一致；固定故事的 case/cluster/improvement 关联可追溯；禁止主张扫描通过。
- PDF：10 页全部渲染，无裁切、重叠、黑块或不可读文字。
- Excel：26 张工作表完成原生格式复验，冻结窗格、打印区域、公式、筛选和验证可用。
- 视频：3 至 5 分钟，固定“合成演示”标识，字幕、画面、声音和敏感信息通过全片复核。
- 离线包：文件可独立打开，清单与 SHA-256 一致，不含凭证或内部路径。
