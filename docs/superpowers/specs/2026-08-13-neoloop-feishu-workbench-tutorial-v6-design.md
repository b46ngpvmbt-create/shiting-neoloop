# 石听 NeoLoop 飞书工作台使用教程 V6 设计

## 目标

产出一条约 135 秒的真实连续操作录屏，对象是飞书多维表格内嵌的“石听 NeoLoop 飞书多维表格工作台”，不是本地 Web 沙盒。

## 时长与取舍

- 90 秒只适合功能扫视，不足以说清两个闭环和人工关口。
- 成片目标约 135 秒，作为之后 5 分钟总演示片中的飞书实操主段。
- 本轮先生成无旁白、无大字遮罩的操作教程母版；配音和无底字幕在总片合成时进入。

## 教程路径

1. 总览：Base 连接、10 张表、当前合成数据口径。
2. 接入与案件：连接器健康、来源边界、原始反馈与人工确认后的案件。
3. 处置与 SLA：处置队列、原始时钟、改派和重试不重置起点。
4. 问题与改进：问题簇、人工立项、7/30 天观察与归档/重开。
5. AI 与审计：exact-5 candidate、exact-14 envelope、`needs_human` 失败出口。
6. 主数据与知识：只做关联证据，不接管车辆或任务状态，知识发布保留人工审核。

## 证据边界

- 录制使用“只读评委”角色，仅展示查看路径，不写入或更改 Base。
- 屏幕中的 `synthetic_experiment` 和未配置连接器必须保留，不宣称企业真实全渠道已接入。
- 保留当次服务端读回的“6 条 / 0 启用 / 6 停用”画面，不用旧视频状态替换。
- 不进行部署、上传、GitHub 推送或赛事提交。

## 画面规范

- 1920×1080，30fps，H.264。
- 使用真实录屏片段编排，不用静态截图假充操作。
- 裁掉 Safari 黑色外边与大部分浏览器顶栏，保留飞书页面与工作台内容。
- 不叠加暗层、大标题卡或底部幕布，避免遮挡操作页面。
- 保留 V1—V5 和两个原始录屏，V6 使用新文件名输出。

## 验收

- 成片时长 130–138 秒，总分辨率 1920×1080。
- 至少抽检总览、接入、案件、SLA、问题簇、AI 审计、主数据七类画面。
- 不出现本地 Web 工作台、Codex 界面、密钥、OAuth 参数或未授权业务数据。
- 画面可读，页面不被说明层遮挡。
