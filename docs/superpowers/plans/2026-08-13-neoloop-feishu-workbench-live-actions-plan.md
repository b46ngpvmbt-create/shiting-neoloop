# 飞书工作台真实操作实施计划

1. 为 Base adapter 增加带字段白名单的 `updateSyntheticRecord` ，实现写前重读、当前值指纹、SDK `setRecord`和写后读回。
2. 新增安全动作合同和纯函数验证，覆盖案件、工单、改进、AI 审核和知识审核。
3. 先新增失败测试：空按钮扫描、角色防线、非合成记录、旧值漂移、字段白名单、字段类型转换和写后读回。
4. 在工作台中新增业务操作小页面、记录选择、表单、二次确认、忙碌态和结果通知。
5. 运行 Node 22.13 的 TypeScript、Web 回归、生产构建和按钮契约扫描。
6. 部署 Netlify Preview，在真实飞书 Base 中逐个按钮验证。
7. 用一条专用 `SYN-LIVE-DEMO-*` 记录分别做成功、取消、越权/漂移失败验证，读回 Base 并记录证据。
8. 验收通过后晋升生产，再次遍历所有按钮；未通过则保留当前生产版本。
