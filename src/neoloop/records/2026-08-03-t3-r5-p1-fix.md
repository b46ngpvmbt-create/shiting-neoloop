- 前置状态要求 cluster 与 improvement 均为“观察中”、current cycle 精确匹配、day-30 尚未记录；数据和证据仍限定为 `synthetic_experiment` 的 repository-issued W5 closure 与同事件保留独立结论。

## 时间与事实边界

- 初始观察成员边界已用 `opened_at-1ms` 成功、`=opened_at` 和 `+1ms` 失败且零写入证明。
- 归档后重开边界已用 `last_archive_at-1ms`、`=last_archive_at` 失败，`+1ms` 成功证明；上界仍为 `closed_at <= reopen_at`。
- active intake 要求 `opened_at < closed_at <= min(now, day30_expected_at)`；day-30 之后或已有 day-30 checkpoint 时失败。
- 若 day-7 已记录，`closed_at <= day7_expected_at` 的漏记迟到 intake 失败；day-7 后关闭且 day-30 前获批的案可进入 day-30 来源。
- W5 provenance、跨簇所有权、窗口、同周期重复四组均有独立负例；失败比较 cluster、improvement、成员、cycle/checkpoint、intake、history、receipt 及案件/反馈快照，证明零部分写。
- `related_task_volume` 的既有事实边界不变：没有可信分母时只保存复发数，`recurrence_rate=null`。本轮没有生成或宣称企业真实复发率。
- N6 仍只保存受控根因假设，不确认最终技术根因；intake 不并案、不改连反馈、不回写案件状态、不发布知识。
